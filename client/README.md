# ReVendo — best overall marketplace identity.

**ReVendo** is a modern, high-performance mobile marketplace built with React Native and Expo for buying and selling items locally and globally.

---

## Key Features

- **Dynamic Feed & Proximity Filters**: Browse listings with distance calculation ("Listings Near Me") and radius filters.
- **Multi-Image Carousel**: Swipeable image gallery with indicator dots and full-screen image viewer on listing details.
- **Two-Way Real-Time Chat**: Direct buyer-seller conversations with message bubbles and unread status.
- **Price Negotiation ("Make an Offer")**: Buyers submit custom price offers; sellers accept or counter directly.
- **Live Listing Management**: Sellers can edit listings, add new photos, or remove individual existing images.
- **Profiles & Dynamic Avatars**: User profiles with custom photo uploads or auto-generated letter avatars.
- **Universal Top Header & 5-Tab Navigation**: Clean navigation across Home, Wishlist, Sell (+), Offers, and My Listings.
- **Wishlist & Recently Viewed**: Save favorites and track previously inspected items.

---

## Technologies Used

- **Frontend**: React Native, Expo (SDK 58), React Navigation 6, Lottie
- **Backend**: Node.js, Express.js, MongoDB, Mongoose, Sharp, Multer
- **Authentication**: JSON Web Tokens (JWT) & Expo SecureStore
- **Push Notifications**: Expo Notifications SDK
